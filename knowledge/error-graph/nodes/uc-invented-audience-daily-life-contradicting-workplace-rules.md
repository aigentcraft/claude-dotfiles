## ユーザーの指摘（原文）

「あと、移動中に顧客情報見たりはしないし、稼働時間はみんな９：００〜２１：００だから、その辺り実情に合わせて」

## 1. Plan / Context

研修資料の共感パート（受講者の毎日を描く場面）。「面談前夜」の心の声と、時刻が進む演出（22:40 → 0:10）、カレンダーのモックを作った。

## 2. Do / The Error

- 心の声に「Aさんの経歴書は、移動中に読むしかない」を入れた。実際は **移動中に顧客情報を見ない**（情報の扱いの規則）
- 時刻を 22:40 → 23:25 → 0:10 と進めた。実際の稼働時間は **全員 9:00〜21:00**
- カレンダーのモックにも「移動 40分」を入れていた

## 3. Check / Root Cause

- **前日に自分で「心の声は作らず、現場から集める」と書いた（同クラスターの別ノード）のに、試作では想像の例をそのまま本番の言葉として使った。** 「仮の言葉」という印も付けていなかった
- 感情を強めたくて、極端な状況（深夜・移動中）を足した。**極端さは共感ではなく「うちはそうじゃない」という違和感を生む**
- 受講者の職場の前提（情報の扱い・稼働時間・面談の形）を、作る前に一つも確かめていなかった

## 4. Act / Prevention Strategy (Fix)

- 稼働時間の中（19:30 → 20:15 → 20:50）で準備が追いつかない場面に変える。移動の描写はすべて消す
- 心の声は「確かめた事実」だけで組み、想像の部分は仮の言葉として本人に見せて確認する

### 予防ルール

1. **受け手の日常を描く前に、職場の前提を確かめる。** 情報の扱い（どこで何を見てよいか）・稼働時間・仕事の形（対面かオンラインか）
2. **規則に反する行動を「あるある」として描かない。** 研修資料が規則違反を当たり前のように見せることになる
3. **想像で補った言葉や場面は「仮」と明示して出す。** 自分で書いた予防ルールは、次の成果物で守れているかを出す前に照合する
