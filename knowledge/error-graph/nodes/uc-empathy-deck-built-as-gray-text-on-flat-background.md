## ユーザーの指摘（原文）

「無機質だしクオリティ低すぎるな」

## 1. Plan / Context

現場の担当者向け研修の試作（PowerPoint・変形トランジション・3 シーン 11 コマ）。
本人の要求は「日常の感情に共感しながら、素直に受け入れられる流れ」「モーショングラフィックスのようなインパクト」「過去の AI 製スライドは雰囲気的でメリハリがなかった」。

## 2. Do / The Error

- 全コマが **白地（または黒地）に文字だけ**。色は灰色の濃淡と朱色のアクセント 1 色
- 候補者のカードは灰色の四角と棒線、比較は素の表。絵・写真・人物・奥行き・質感が一つもない
- 点検は「はみ出し・改行・切り替え効果の有無」だけで合格にし、品質の水準そのものは測っていなかった
- 本人の設計ルール（design-quality）は **「白地に灰色＋装飾のアクセント 1 色」「奥行きのない平面レイアウト」を禁止パターンとして明記**しており、それが読み込まれた状態で作っていた

## 3. Check / Root Cause

- **「メリハリ」を文字の大小だけで解こうとした。** 目的は感情を動かすことなのに、感情を運ぶもの（人・場面・光・温度）を何も置かなかった
- **点検が「欠陥がないか」だけで、「水準に届いているか」を見ていなかった。** 欠陥ゼロは完成ではない
- **配色を内容から決めていない。** 物語には「夜（面談前夜）→朝」という明確な温度の流れがあるのに、どの資料にも使える灰色＋1 色にした
- 絵を図形の組み合わせで済ませようとした（四角と棒線の「経歴書」）。手元に画像生成の手段があるのに検討しなかった

## 4. Act / Prevention Strategy (Fix)

- 作り直しの前に美術の方向（内容から決めた配色・繰り返す絵のモチーフ・絵の出どころ）を言葉で決め、禁止パターンと照らしてから作る
- 共感パートは人の場面（絵）で語る。文字は場面の上に重ねる

### 予防ルール

1. **見た目の成果物は、作る前に美術の方向を書く。** 配色は内容（物語の温度・時間帯）から決め、「白地＋灰色文字＋アクセント 1 色」は既定で禁止
2. **点検は 2 段。** ①欠陥（はみ出し・改行・重なり）②水準（各コマに絵か図があるか・奥行きがあるか・目的の感情を運ぶものがあるか）。①だけ通っても完成ではない
3. **感情を動かす資料は、文字だけで作らない。** 人の場面・光・温度を置く。図形の組み合わせで絵を代用しない（画像生成など手元の手段を先に検討する）
4. 本人の設計ルールに禁止パターンが書かれていたら、作った物をその一覧で自己点検してから見せる
