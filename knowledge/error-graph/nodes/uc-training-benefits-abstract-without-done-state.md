## ユーザーの指摘（要旨・本人が打ち合わせで受けたフィードバック）

「メリットをもっと具体的に伝えないとわからない」「どういう状態になっていればできているということになるのかが疑問点として残る」「導入部分が複数ページにわたって時間として伸びそう」（持ち時間は15分）

## 1. Plan / Context

社内AIチャットの使い方を新メンバーに展開する研修資料。共感 → 比較 → 体験 → 次の一歩の流れで21枚を作った。

## 2. Do / The Error

- メリットを「専属サブ担当」「下ごしらえ」「型×文脈」など **比喩と概念** で語り、何を入れると何が返ってくるか（実物の出力）を見せていなかった
- **合格ライン（できている状態）** が無く、腰の重い人が「どこまでやればいいか」を判断できなかった
- 共感の導入に6枚を使い、持ち時間（実際は15分）を確かめていなかった

## 3. Check / Root Cause

- 気持ちを動かす流れを重視するあまり、**行動を決める材料**（具体的な出力・合格ライン・同じ条件での比較）が抜けた
- 「やってみよう」と思った人が次に知りたいのは「何ができて、どこまでやればOKか」。比喩はそこに答えない

## 4. Act / Prevention Strategy (Fix)

- 構成をやり直し、①入れるもの → 返ってくるもの ②合格ライン（例：候補者ごとのチャットでマッチングや提案の仕方を相談できる）③同じ候補者・同じ依頼で「あり／なし」の出力比較 を中心に置いた。共感の導入は1枚に縮めた

### 予防ルール

1. **導入研修には、具体的な出力・合格ライン・同条件の比較の3つを必ず入れる。** 比喩は補助に留める
2. **持ち時間は構成を作る前に確かめる。** 導入は全体の1割程度に収める
