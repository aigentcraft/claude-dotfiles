## ユーザーの指摘（原文）

「ブロブはクリック時じゃなくて常にフヨフヨ動いてる感じにできたらしてほしい。動きに切れ目があって不自然。」

## 1. Plan / Context

PowerPoint の研修資料。背景に淡いブロブを置き、コマごとに位置・角度・大きさを少しずつ変えて、変形（モーフ）でつないでいた。

## 2. Do / The Error

- ブロブが動くのはクリックした瞬間の約1秒だけ。話している間は止まっていて、クリックのたびに急に動く
- 「装飾の常時の動き」と「内容の切り替え」を、同じ仕組み（スライドの切り替え）に載せていた

## 3. Check / Root Cause

- 変形はスライドの切り替え効果なので、**動きの単位がクリック**になる。常に漂う動きは原理的に作れない
- 動きの役割（内容を変える動き／空気をつくる動き）を分けて設計していなかった

## 4. Act / Prevention Strategy (Fix)

- ブロブの位置は全スライドで共通にし、各スライドに **繰り返しのアニメーション**（弧を描く移動・揺れ・拡大縮小の往復、開始は「前と同時」でスライド開始時に自動、繰り返しは「スライドの最後まで」）を付けた。周期をずらして機械的に見えないようにした
- PowerPoint はスライドが変わるとアニメーションを最初からやり直すため、切り替えの瞬間だけは初期位置に戻る。動く幅を小さめにして目立たなくした（本人にも伝える）

### 予防ルール

1. **常に動く装飾は、スライド内の繰り返しアニメーションで作る。** 変形などの切り替え効果は、内容が変わる動きにだけ使う
2. 動きを設計する時は「何が・いつ（クリック／常時）・どれくらい」を役割ごとに分けて決める
