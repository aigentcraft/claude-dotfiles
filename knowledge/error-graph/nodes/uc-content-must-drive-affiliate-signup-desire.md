## 症状（Symptom）

Fable 5.1 速報記事のやり直し（比較プロトコル docs/11・競合カバレッジ Q15）とベンチランナー実装に取りかかっている最中に、ユーザー:
**「アフィリエイトで稼ぐのがそもそもの趣旨なんだから、使いたくなる、アフィリエイトリンクから登録したくなる発信をしないとダメでしょうが」**

- 記事もツイートも「正確に測る・公式の事実を分かりやすくまとめる・競合を超える」までは仕組みにしたが、
  **「読んだ人がその製品を使いたくなり、アフィリエイトリンクから登録する」** という成果（確定報酬）に向けた契約が、企画〜執筆〜検閲〜X のどこにも無い
- 直近の改善（弁別性・カバレッジ・公式事実+メディア）はすべて「情報の質」の軸で、「売上の軸」を誰も持っていなかった

## 根本原因（Root Cause）

実査（2026-09-03・Explore 56 ツール呼び出し）で判明した事実:
1. **offers テーブルは 0 行** — 案件が 1 件も登録されていない。docs/01 は「ASP 契約手続き（申請・口座登録）」を人間の唯一の作業と定めたが、
   それを **催促する仕組みが無い**。02b_assign_offer は 16 回連続で「提携済み案件なし — 集客記事として続行」を info で記録し rc=0（run_pipeline でも critical=False）
2. その結果 affiliate_links 0 行 → 04 の CTA 機械挿入は何も入れず → 公開 5 本・承認待ち 10 本すべて **CTA ゼロ・アフィリエイト要素ゼロ**。
   看板の VPS 比較記事は「契約前に公式ページで最新の金額を確認してください」で終わる（読者を突き放す）
3. reviewer に「使いたくなるか」の検査が無い。Q09 は CTA の **抑制** 検査で「案件未アサインなら CTA なしが正しい」と明示的に免除・重み 0.5。
   Q13（初心者適合・checklist では 2.0）が code の Q_WEIGHTS に無く 1.0 に落ちていた。C04/C05/C08 + writer の「訴求は実測値+合わない人のみ」で、文体への圧は下方向だけ
4. writer は存在しない `{{affil:offer-slug}}` 構文を教えられていた（解決コード無し）。実際のマーカー `<!-- aff-cta -->` は案件がある時だけ出る offer_block にしか無い
5. seo-strategist の `<!-- CTA: 案件確定後に差し込み -->` は strip_internal_notes で削除され、「収益枠を保留した」記録が残らない
6. 企画: `offers_brief` が 0 件時に「案件なし — 全記事は集客記事として制作される」と **正常状態として** 提示 → 観点②（CV 近接）が自動で無効化。
   収益 KW 比率 3:7〜6:4 の機械検査なし。docs/04 の優先度式（検索Vol × 案件単価 × CVR）は未実装
7. X: 仮説の metric は全部 x_engagement_rate。Tips は URL なし完結型が契約。クリック/セッション/収益データは strategist に渡らない
8. KPI: CTR（クリック/セッション 5〜10% 目標）と CVR はどこでも計算されない。`site.offers_approved=0` を 6 日連続で記録しているが誰も読まない

要するに **「案件が無い」を全員が正常と見なす設計** になっていた。情報の質の軸（正確・弁別・網羅）だけが強化され、売上の軸は誰も持たなかった。

## 予防ルール（Prevention）

- **成果の軸は「確定報酬」**。情報の質（正確・弁別・網羅）は必要条件であって十分条件ではない。新しい契約・検査を足すときは
  「これは読者を登録に近づけるか」を 1 行で答えられなければ足さない
- 記事は「使いたくなる根拠（実測で見えた具体的な得）」+「登録の最短導線（迷ったらこれ・最初の 5 分）」を最初の 1 画面に。
  案件が付かない題材は、必ず案件が付く題材への橋（この記事から次に読む/使うもの）を持つ
- X は「読みたくなる → 記事へ → 登録」の一本道で設計し、aim に conversion 系（click/signup）を持たせて予測→実測で回す
- 企画の選定条件に案件の有無・報酬・成約しやすさを入れる（案件が無い題材だけで日々を埋めない）
