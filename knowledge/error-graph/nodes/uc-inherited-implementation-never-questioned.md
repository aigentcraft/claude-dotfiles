## 症状（Symptom）

受信箱のスレッドが押し出されて見つからなくなる問題に対し、
**「取り残しがある時だけ受信箱を 5 ページ深く読む」救出処理**を設計・実装・検証し、
自信を持って報告した直後。

利用者 **「てかメッセージ箱ごとの URL を記録するエージェント作って、DB に記録して
メッセージ送信も内容の確認も URL に飛べばいいんじゃないの？何かそうしない理由があるの？」**

調べたら **そのとおりだった。**

```
https://mamaworks.jp/chat_status?client_id=7141   → その企業のスレッドだけ（実測 1 件）
```

`client_id` はサーバーが返す HTML にそのまま入っていた。

```html
<worker-messenger initial-client-id="7003" initial-worker-id="730061" …>
```

さらに同じ HTML の `<select name="client_id">` には**全企業の対応表**まであった
（連絡 15 件・スカウト 41 件。1 ページ目の 10 件ではなく全件）。

つまり **ページ送りも企業名の文字列一致も、最初から不要だった。**

## 根本原因（Root Cause）

**既存実装を「与えられた前提」として受け取り、その前提自体を調べなかった。**

- 前のセッションが書いた `findCompanyBlock`（企業名で最大 10 ページめくる）を見て、
  「ページ送りが必要な構造なのだ」と解釈した
- 実際には「そう実装されている」だけで、「そうするしかない」ではなかった
- **私が最初に発した問いは「どう直すか」であって「なぜこうなっているか」ではなかった**

見落としを助長した要素が 2 つある。

1. **ハイドレーション後の DOM しか見ていなかった。** `page.evaluate` で属性を洗って
   「`client_id` は HTML に出てこない」と結論し、利用者にもそう報告した（**誤り**）。
   Vue が描画すると属性が消えるだけで、サーバーが返す生 HTML には入っていた。
   *見えなかった* を *存在しない* と書いた
2. **直前の成功が疑いを鈍らせた。** 救出処理は実際に動き、止まっていた案件を復帰させ、
   故障注入でも検知を確認していた。**正しく動くものを作った達成感が、
   「そもそも要るのか」を問う機会を奪った**

## 修正（Fix）

- `client_id` を記録に持たせ、`?client_id=N` でスレッドを直接開く方式へ移行
- 取得は**遷移のレスポンス本体を捕まえる**（追加リクエストなし）
- 救出は 13 秒 → 4 秒。ページ送りは ID を持たない古い記録だけの退避経路に降格
- Discord の通知にスレッドへのリンクを付けた（人間も受信箱を探さずに開ける）

なお **送信 API（`POST /chat`）は採らなかった。** JS に `direction_flag` が
`1` と `0` の 2 箇所あり、どちらがどのコンポーネントか特定できない。
「誰からのメッセージか」を決める値の可能性が高く、不可逆操作でこの曖昧さは踏めない。
URL 方式なら同じ利得が得られ、送信は画面操作のままなので既存の安全弁も残る。

## 予防ルール

1. **既存実装は「制約の証拠」ではない。** 引き継いだコードが遠回りをしていたら、
   直す前に **「サイトはこれを直接できる手段を持っていないか」** を一度だけ調べる。
   調べるコストは数分、放置するコストは全実装分。
2. **「見えない」と「存在しない」を区別して書く。** `page.evaluate` で取れないのは
   *その時点の DOM に無い*だけ。生 HTML・レスポンス・JS バンドル・API を当たる前に
   「存在しない」と報告しない。
3. **スクレイピング対象は、まず自分の URL 設計を調べる。** 検索フォーム・フィルタ・
   ページャの `<form>` は、そのサイトが公式に提供している絞り込み手段の一覧である。
   実際この件も `<select name="client_id">` を持つ検索フォームが答えだった。
4. **うまくいった直後ほど「そもそも要るのか」を問う。** 動くものを作った達成感は、
   前提への疑いを鈍らせる。検証を通った時が、設計を疑う最後の機会。
5. **利用者の素朴な問いを説明で潰さない。** 「なぜそうしないのか」に対して
   既存実装の事情を並べれば会話は終わるが、答えにはならない。**先に測る。**
