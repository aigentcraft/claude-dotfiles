## 指摘（原文）
> あと成果の不変条件が3件成立とかいう通知がディスコードに来てるよ、直してほしいし、
> 通知の内容も直感的にわかりずらいからそれもやめてほしい、直感的にわかる内容にしてほしい

題名は実際には「🚨 成果の不変条件が **3 件不成立**」。**「成立」と読み違えられている**。
1 文字で意味が反転する語を、毎朝 3 回、10 日続けて送っていた。

## 実物（2026-09-21 09:30 に届いたもの）
```
🚨 成果の不変条件が 3 件不成立
**始めた作業が終わっていない**: 終わっていない記事生産 1 件 / 終わらない担当の作業 0 件 / 最後の開始は 3.5 時間前
・記事の生産が 2026-09-20 13:00:01 に始まったまま終わっていません（11 時間経過）
**X の発信が止まっている**: 24 時間の投稿 0 本 / 止まっている発信 2 種類
・記事の告知（article_link）が 5.8 日止まっています（最終 2026-09-15 05:01:25）
```

## 何が分かりにくいのか（実物に即して 6 つ）
1. **内部語**: 「不変条件」「不成立」。数学の語で、しかも肯定形と 1 文字違い
2. **誰が動くのか書いていない**: 3 件とも人間には打つ手が無い（コード側の修理か、機械が自動で直す）
   のに、🚨 で 10 日間鳴り続けていた
3. **0 件の事実が見出しにいる**: 「1 件 / **0 件** / 3.5 時間前」。何が問題かが読めない
4. **時刻が UTC**: 読む人は JST。「13:00:01」は実際には 22:00。しかも同じ通知の中で
   見出しは「3.5 時間前」、説明は「11 時間経過」と**別の run の話**が並んでいた
5. **識別子が残っている**: `article_link` `thread` `editor`。この指摘は**4 回目**
6. **毎回同じものが届く**: 抑止はあるのに一度も効いていなかった（下の根本原因）

## 根本原因
**通知が、検査のデータ構造をそのまま文字列化したものだった。**
`Check` が持つのは name / ok / value / detail の 4 つだけで、
「誰が直すか」「次の一手」「何日目か」を入れる欄がそもそも無い。だから書きようがない。

抑止が効かなかったのも同じ根: 鍵が `{検査名: 現在値}` の**文字列比較**だった。
値には「最後の開始は 3.5 時間前」「今日の拒否 17/341 回」のように毎 run 変わる数字が入るので、
**前回と必ず違う** → 毎回送信。実データで数え直すと 25 回の赤 run すべてが送信判定だった。

## 直し方
- `Check` に **owner**（human / code / auto・既定は human = 否定側）と **next_step** を持たせ、
  **検査関数が状況を見て決める**（名前引きの静的な表にしない。同じ検査でも状況で持ち主が変わる）
- 題名は owner から作る: 人の出番があれば「🔴 あなたに対応してほしいこと N 件」、
  無ければ「🟡 コード側で直すこと N 件（あなたの操作は不要です）」
- 本文は 1 件ずつ「🆕 今日 / 🔁 N 日目」「何が起きているか」「→ 直すのは: 誰 / 次の一手」
- 時刻は JST・経過は整数の日か時間・0 件は見出しから落とす・識別子は対応表にあれば出さない
- 抑止は**検査ごとの送信時刻**で持つ（24 時間に 1 回）。現在値の文字列で比べない
- **計算していないことは書かない**。原因や影響をもっともらしい文字列で足すと、
  種別から固定文字列を書いて嘘になった画像ラベルの件と同じ型になる

## これは同じ型の 2 回目
2026-09-06 に参照プロジェクトで [[uc-mechanical-notifications-lack-situation]]
（「ディスコードへの通知も機械的でよく状況がわからん」）を受けている。
そのときの結論は「判断に必要な事実はすべて DB にある。集めて書いていなかっただけ」。
weevee の成果チェックは**その後に作った通知**なのに、同じ形で作ってしまった。
新しい通知を足すときは、既存の良い型（日次通知の「■ あなたのやること」）に寄せる。

## 予防ルール
- **人に送る文は「読んだ人が次に何をするか」から書く。** 状態の羅列から始めない
- 通知を作ったら、**実物を 1 通自分で読む**（--dry-run の出力ではなく、届いた文面）
- 抑止の鍵に、毎回変わる値を入れない。鍵は「何が起きているか」であって「今いくつか」ではない
- 肯定形と 1 文字違いの否定語（不成立 / 未達 / 非対応）を題名に使わない
