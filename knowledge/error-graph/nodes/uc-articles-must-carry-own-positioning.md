# 「認定パートナーの選び方」記事が、非認定の自社を選択肢から外していた

## 症状（ユーザー指摘・記事承認直後）
「パートナー制度をプーリーは持ってないから、自分で受注受けづらくなってるよね。
認定は広告費である分ブランド委託費が上がる。技術は公認でもクライアントの実務を
知らないため形だけのシステムになる。プーリーなら両方を理解したエンジニアが現場と
コミュニケーションを取りながら伴走できる——みたいに自社へのアプローチをしないと。今後も含めて」

## 何が起きたか
公認パートナー認定・CyPN評価・認定資格を「選び方の基準」として推す記事を公開した。
情報としては正確で検閲も通ったが、**非認定のpullieはその基準で選ばれない側** —
読者が記事の教え通りに動くほど自社の受注から遠ざかる構造だった。

## 根本原因
記事生成の目的関数が「SEO的に良い中立記事＋CTAリンク」で止まっていた。
媒体の存在目的（受注 — docs/01に明記）のうち、**「なぜpullieに頼むのか」という
ポジショニングの注入は誰の実行ルールでもなかった**（CTA=導線の置き場所ルールは
あったが、選ばれる理由の言語化は無かった）。設計書にある目的も、エージェントの
SKILL/skill_refsまで落ちていなければ生成物に現れない。

## 修正
- `agents/writer/skill_refs/positioning.md` 新設: コアナラティブを一元化
  （①認定=外形の証明として尊重 ②構造的トレードオフ2点: 取得維持コストの事実・
  業務理解は保証されない ③対置軸=現場実務経験×技術の伴走 ④着地=読者への判断軸提供）
  + 記事タイプ別適用（比較・選び方・費用・外注系は必須1節/dogfoodingは適用しない）
  + C系整合の禁止事項
- writer・sns-manager・seo-strategist のmanifestへ結線（企画段階から接続点を指定）
- 公開済み記事へ実適用し、reviewer C系スポット検閲で初稿の
  「価格に転嫁されやすい」が **F03（FS外の推論）+C08（競合の立場からの間接批判）** で
  fail → 「コストは事実・織り込み方は非公開・だから内訳確認」へ修正して pass

## 予防ルール
1. **媒体の存在目的（受注）はエージェントの実行ルール（SKILL/skill_refs）まで落とす**。
   設計書に書いてあるだけの目的は生成物に現れない。「中立な良記事」は目的の半分
2. **比較・選び方系の記事は「読者の判断軸に自社の土俵を1つ加える」まで書いて完成**。
   他社・他制度の基準だけで選ばせる記事は、自社がその基準を満たさない限り逆導線
3. 自社優位の主張は必ず検閲を通す: 競合構造に触れる文は
   **F系（出典なき推論の断定禁止）とC系（誹謗・誤認・断定）に最も抵触しやすい**。
   誠実な形（事実+非公開の明示+読者の確認行動への接続）に変換してから出す
4. ポジショニングは記事だけでなくSNS・リード返信にも同じナラティブで通す（一貫性が信頼）
