## ユーザーの指摘（原文）

「ペルソナ足りないときは何が足りないのか具体的に連絡を入れさせて、ディスコード上に返信したらそれをペルソナに登録してほしいんだよね。出先でいちいちPC開くのだるいよ」

## 何が起きたか

応募の記入で人物像に無い情報があった時、Discord に出す案内は
「`persona.md` に事実を足してから［応募内容を作る］を押し直す」だった。

- **何が足りないのかを書いていなかった**（エージェントの「進めない事情」を読み解く必要があった）
- **足す手段が PC のファイル編集だけ**だった。利用者は出先ではスマホの Discord しか持たない

## 根本原因

- HOOTL の原則（人間の介在は初回ログインだけ・以降は Discord で完結）を、**人に頼む操作**にまで当てはめていなかった
- 「人に頼む」を「人が手元でファイルを直す」と同一視した。頼む相手がどこにいるか（出先・スマホ）を考えていなかった
- 足りない情報を**構造化して受け取っていなかった**（blockers の自由文だけ）ので、質問にも登録にも使えなかった

## 予防ルール

1. **人に何かを頼む時は、Discord の返信やボタンで完結させる。** ファイル編集・PC 操作を求める案内は設計の穴
2. 足りない情報は**項目ごとに構造化して受け取る**（項目名と本人への質問）。自由文の理由だけでは次の行動に繋がらない
3. 人が答えたら、**登録した内容を返して確認できるようにし**、止まっていた作業を自動で再開する
