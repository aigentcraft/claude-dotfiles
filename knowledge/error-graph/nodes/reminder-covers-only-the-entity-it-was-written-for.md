## 症状

人間からの報告 — 「**Noteが動いてないみたいよ**」。

実際、note は **2026-09-03 から 6 日間、1 本も作られていなかった**。
エラーは 1 件も出ていない。パイプラインは毎朝正常に完走していた。

## 何が起きていたか

1. 2026-09-03 に note#10 が生成され、Discord に承認依頼が 1 回送られた
2. 人間はそれを読み飛ばした（HITL の通常の失敗）
3. `note_pipeline/01_compose.py` は先頭でこう戻る:
   ```python
   if con.execute("SELECT 1 FROM note_posts WHERE status IN ('review','approved')").fetchone():
       print("note skipped: 承認待ち/投稿待ちが滞留中（先に処理される）")
       return
   ```
   → **未処理が 1 本でもあると、レーン全体が生成を止める**
4. 督促は来ない。`09_notify` の放置承認リマインダーは **`articles` しか見ていなかった**

決定的なのは、**同じ故障をすでに一度直していた**こと。2026-08-23 に
「リード#2 が受信通知 1 回きりのまま 8 日間滞留した」を受けて、
`3) 承認リマインド`（articles）の**すぐ隣に** `3b) リード返信の督促`（leads）を足している。
`note_posts` はその時も対象外で、**エンティティが 1 つ増えるたびにブロックを足す形**
だったので、後から生えたレーンが静かに抜けた。

沈黙ウォッチドッグ（5 日で発火）は 09-09 05:57 JST に**実際に鳴っていた**。
ただし文面は「note の生成が 6 日間動いていません／原因を調査して直してと依頼してください」
だけで、**原因である「承認待ち 1 本」をどこにも含んでいなかった**。
鳴ったが、鳴っただけだった。

## 根本原因

**HITL の滞留督促を「エンティティごとの if ブロック」で実装した。**
列挙は閉じない（[[enumeration-guards-never-close-use-structural-rules.md]]）。
レーンを増やす側は「新しいレーンを作った」としか思っておらず、
通知側の列挙に自分を足す必要があることに気づかない。

さらに悪いのは、**note は記事と滞留の意味が違う**こと。記事は 1 本止まっても次が作られるが、
note は 1 本の未処理でレーン全体が止まる。
**同じ「承認待ち」でも、止まる範囲が違うものを、通知の設計だけ記事に揃えていた。**

## 修正

- `09_notify` に `note_posts` の督促を追加。記事側と同じ「このrunで承認依頼を出したものは除く」
  （`note.approval.requested` を `since` で除外）を使い、二重通知にしない
- 文面に「**この間、新しい note は作られません**」と、その根拠（`01_compose` の早期 return）を書く
  — 人間が「後で読めばいい」と判断できないようにするのは、督促ではなく**影響範囲の提示**
- 沈黙ウォッチドッグには**原因の断定を書かず**、レーンの現在値（最後の生成時刻／未処理の一覧）を並べる。
  未処理が空なら「なし」と出る = 承認以外の原因だと人間が読み取れる
  （断定文を `if` で出すのは [[uc-hardcoded-judgment-while-fixing-hardcoding.md]] の再生産）

## 予防ルール

- **「人間の1アクションを待つ状態」を新設したら、その状態の督促がどこにあるかを同時に確認する。**
  承認・返信・アップロード待ちはすべて同じ故障をする。通知は 1 回では届かない前提で設計する
- **滞留督促を書くときは、対象を entity ごとの if で並べない。**
  並べるなら、新レーン追加時に必ず通る場所（レーン定義・レジストリ）から引く。
  最低限、**同種のブロックが既に隣にあるなら「他に対象はないか」を必ず問う**
- **「1 件の滞留が何を止めるか」を、通知の本文に書く。**
  止まる範囲が違えば、同じ「承認待ち」でも人間の優先度は変わる
- **沈黙ウォッチドッグは「鳴ること」がゴールではない。**
  鳴った文面に、次の 1 手を決められる材料（原因の候補ではなく**現在値**）が入っているか確かめる。
  入っていなければ、それは人間に調査を丸投げしているだけで、人間が自力で気づくのと同じ
