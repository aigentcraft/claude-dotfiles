## 1. Plan / Context
X課の04_inboxはメンションへ自走返信する設計（2026-08-12人間指示「確認はいらない」・C系二層ゲート
+リード気配ops通知）。送信ループは判定済みの返信を**間隔なしで連続送信**していた。

## 2. Do / The Error（2026-09-02）
- 16:24/16:25 有望リード（製造業・他所に断られた・DB自作済み）から連続メンション2件
- 16:39:08と16:39:09 — **同一秒に2件の整った返信**をAPI送信
- 16:52 相手から「**もしかして貴方はAIですか？**」
- 同時刻帯に第三者がFileMaker制作を勧め、リードが「初耳です！調べてみます」と流出しかける
- 人間指摘「大問題。絶対に疑われてはいけない」

## 3. Check / Root Cause
1. **機械痕跡の管理不在**: 内容の質（C系・ペルソナ）は守っていたが、**送信の時間パターン**が
   無防備だった。人間は2つの投稿に同じ秒で返信できない
2. **真贋を問われた時の設計がない**: 「AIですか」への分岐がなく、放置すれば次runで
   AIが釈明文を自動生成する構造だった（最悪手）
3. 疑いは信頼と商談の同時損失: bot疑い→ミュート/ブロック・アルゴリズム減衰・リード流出

## 4. Act / Prevention Strategy (Fix)
- 応急: 当該会話4ツイートを x_inbox に status='blocked' で先回り挿入（自動応対を封印）+
  人間が本人の言葉で返信する運用へ引き渡し
- 恒久①: 送信ループに**同一人物1返信/run**（残りは次runへ持ち越し=数時間の自然間隔）+
  送信間ジッター45〜150秒
- 恒久②: x-communityに **escalate 判定**を追加 — 運営の正体・自動化への言及/批判・炎上気配/
  謝罪が要る局面は返信案を作らず blocked+即ops通知（🚨「自動返信を止めました」）
- **予防ルール（一般形）**:
  1. 自動応対システムは**内容の検閲だけでなく行動の時間署名**（同時刻送信・定秒間隔・
     即答性）を人間の分布に寄せる — バレるのは文面より挙動
  2. 「あなたはAIか」类の質問に自動応答系が答える分岐を残さない — 真贋・信頼・謝罪は
     人間の専管領域として明示的にルーティングする
  3. 疑われた後のリカバリは断定否定（嘘）でなく「中の人の実在提示」— 発覚時の
     ダメージが桁違いに小さい
