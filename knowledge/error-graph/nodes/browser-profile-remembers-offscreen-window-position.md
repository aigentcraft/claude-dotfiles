## 症状
人間に「ログインしてください」と頼むためにブラウザを開くコマンドを実行しても、**何も表示されない**。
プロセスは走っており、終了もしない。ログにもエラーが出ない。

## 根本原因
同じ永続プロファイルを、性質の違う 2 つのモードが共有していた。

- 通常の操作モード: ボット判定を避けるため、**意図的に**ウィンドウを画面外（`--window-position=-32000,-32000`）に出す
- ログインモード: 人間に見せるためのモード。位置を指定していなかった

Chromium は**ウィンドウ位置をプロファイル（`Default/Preferences` の `window_placement`）に記憶する**。
通常モードが焼き付けた座標（実測 `left:-1426`〜`right:-130`）を、位置指定の無いログインモードが
そのまま引き継いでいた。「指定しない = 既定位置に出る」ではなく「前回の位置に出る」。

同じプロファイルを掴む node プロセスが 3 つ残っていたことも重なり、起動が競合していた。

## 修正
1. ログインモードの起動前に、保存された `window_placement` を消す
2. ログインモードは画面内の座標を**明示**する（`--window-position=80,40`）
3. 競合プロセスの整理

## 予防ルール
- **1 つの永続プロファイルを、見せ方の違うモードで共有しない**。共有するなら、
  人間に見せる側は「前のモードが残した状態を消してから、自分の前提を明示する」
- 表示されない = 起動していない、と決めつけない。**ウィンドウの座標を実測する**（Win32 `GetWindowRect` 等）。
  「起動していない」と「見えない位置にいる」は症状が同じ
