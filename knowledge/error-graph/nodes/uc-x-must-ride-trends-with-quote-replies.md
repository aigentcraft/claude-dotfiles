## 症状（Symptom）

ユーザー: **「X の投稿なんだけど、全然 AI の情報を引用リプライして発信したりもしてないし、注目を集められていません。文字だけダラダラってしてるし、
AI 関連で伸びているツイートをどのように分析しているのか、全くわかりません。全然参考にできていない気がします。
今だと GPT の ASTRA っていうモデルがすごく話題になっていて、動画を投稿している人たちがたくさんいるので、みんなそれを引用リプライして、
ヤバすぎだろみたいな投稿をして、インプレッションを稼いでます。そういうのが全然。ただダラダラダラダラ。
BB で観測しますみたいなツイートって、全然いらないし、誰向けに発信してんの？って感じがします。」**

## 根本原因（Root Cause）

実データで確認（2026-09-04）:
1. **x_observations 40 行すべてが `source='account:*'`（公式アカウントの巡回）**。伸びている第三者の投稿（バズ投稿）を 1 件も集めていない。
   計画駆動観測（listener が毎朝どこを見るか決める）は実装したが、**探索先が固定アカウントに限られ、検索による発見が無い**
2. **引用の実績ゼロ**。07_amplify（引用増幅）はブラウザ UI 経路（quote_tweet_id は 2026-02 規制で 403）で、`tools/x_login_setup.py` が未実行のため一度も動いていない。
   しかも黙ってスキップしていたので、人間に「ログインが要る」と督促されていない
3. **分析が散文だけ**。x_plans の作戦メモは所感（「装飾を削ぎ落とす実験」等）で、
   **どの形式が何インプレッション取れているかの数表が strategist に渡っていない** → 「どう分析しているか分からない」は正しい
4. 出力が Tips 偏重（テキストのみ・自己完結・URL なしが契約）で、**トレンドに乗る導線が構造上存在しない**
5. filler 検査は「注視中・近日公開・続報」等を弾くが、**「観測します」「見ていきます」型と、持ち帰りゼロの投稿**は通り抜けていた

## 修正（Fix）

（実装中 2026-09-04）
- **トレンド発見**: 01_observe に検索収集を追加（`source='trend:<query>'`）。1 サイクル 3 クエリ × 20 件の上限つき。migration 010 で media_type / is_quote / engagement_rate 等を保存
- **数値分析**: `workers/shared/x_analytics.py` が形式（動画/画像/なし・長さ・箇条書き・引用・数値・疑問形・時刻帯）× インプレッション中央値の**数表**を作り、listener / strategist / 週次検証に渡す。件数不足は「判定不能」と書く
- **引用レーン**: 07_amplify を毎サイクルの主力に格上げ（既定 引用 2 + Tips 1）。ログイン未了なら投稿を保留して Discord に督促（黙って落とさない）。API で可能な reply は代替経路
- **価値契約**: 「観測します」型と持ち帰りゼロを機械で不合格に。引用は「引用先の新規性 1 行 + weevee の具体 1 つ + 次の行動」を必須（空リアクション禁止）

## 予防ルール（Prevention）

- **観測は「決めた場所を見る」だけでは足りない。「いま伸びているものを探す」経路を必ず持つ**。固定アカウントの巡回は土台であって発見ではない
- 分析の成果物は**数表**にして判断者（strategist）に渡す。散文の所感は分析ではない（[[uc-model-comparison-too-shallow-competitor-bypass]] と同じ「実行されたが効いていない」型）
- **人間の作業待ちで止まっているレーンは、黙ってスキップせず督促する**。ログイン待ちのまま数週間動かないのは設計の欠陥
- SNS の出力は「誰に向けた何の持ち帰りか」を機械で要求する。関連: [[feedback_x_posts_value_with_media]] [[uc-x-posts-must-deliver-official-facts-with-media]]
