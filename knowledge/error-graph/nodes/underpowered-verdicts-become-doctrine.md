## 1. Plan / Context
SEO・SNSは正解のない領域なので、pullie は自律的に「効いた／効かなかった」を学ぶ設計を持つ。
x-listener が観測 → x-strategist/x-analyst が仮説を `hypotheses` に登録 → `sns_posts.hypothesis_id`
で実験を紐づけ → 週次 x-analyst が adopted/rejected/extend を判定 → knowledge-curator が
**採用も棄却も** `domain_knowledge` へ昇格 → `feedback_loop` が全エージェントのプロンプトへ注入。
「失敗が消えないPDCA全周」として2026-08-13に完成させたもの。

## 2. Do / The Error（発覚 2026-09-04・人間の問い「正解がない中でどう組織が学んで成長するのか」）
配管は設計どおり動いていた。実測したのは**流れている信号の量**。

| 学習の材料（全期間累計） | |
|---|---|
| X | 91投稿で累計 1,394imp・**いいね7件**（91投稿中 **84件がいいね0**） |
| SEO | 累計 **3クリック**・274imp・平均順位46位 |
| リード（最終的な正解） | **1件** |

| その上の学習機構 | |
|---|---|
| 仮説 | 17件（active 16 / adopted 1） |
| 実験が紐づいた仮説 | **3件のみ**（残り13件は実験ゼロのまま verify_until を迎える） |
| adopted 1件の根拠 | 3投稿・59imp・**いいね1件** →「エンゲージ率は部門平均の2倍」 |
| domain_knowledge | 307件（verified 180 / candidate 126 / **retired 1**） |
| 由来 | 目視・観察117件 / **実測（仮説検証）1件** / その他188件 |

**いいね1件から「検証済み知識」が生まれ、全エージェントのプロンプトに注入されていた。**

## 3. Check / Root Cause
1. **LLMは「判断できない」と自発的に言わない。** 判定肢が adopted/rejected/extend の3択で、
   `insufficient_data` が存在しない。母数ゼロでも必ずどれかが選ばれる。
   **配管を通した瞬間に意見が知識へ化ける**
2. **増幅器はあるが減衰器がない。** curator は昇格方向にしか働かず（retired 1/307）、
   知識に賞味期限も反証の経路もない。「疑う・減らす」役が組織にいない
3. **閉ループに外部の反証が入らない。** 注入された知識に沿った出力が生まれ、それをまた観測して
   知識が強化される。母数が増えないまま回すと、組織は賢くなるのではなく
   **確信を強めながら間違い続ける**
4. **学習単位が細かすぎる。** 仮説が個別投稿の観察から立つため n=2〜3 にしかならない。
   型（tips/article_link/quote/product）×週で束ねれば同じデータ量で n が一桁増える
5. **過程が還流していない。** `reflections.process_log` は1,027件6.5MB貯まっているが読む主体は
   ダッシュボード（人間向けHTML）だけ。しかも `claude_client` の `if result.ok:` により
   **失敗した実行の思考は保存されない**（失敗45件中41件が空）。母数が薄いときこそ、
   結果（ノイズ）より過程（n=1でも構造的欠陥を示す）から学ぶ価値が高いのに、そこが空

## 4. Act / Prevention Strategy (Fix)
計画へ反映済み（docs/12 §1.2・原理6・Phase 1）。実装はこれから。

- **判定させないゲート**: `insufficient_data` を判定肢に追加して**既定にする**。さらに機械側で
  最低試行数（例 n≥10 かつ impressions≥500）を課し、満たさない仮説はLLMに渡さない
- **失敗時の思考ログを保存**（`if result.ok:` の分岐を外す）
- **知識に由来と賞味期限**: 目視由来＝仮説 / 実測由来＝実証 を注入時に区別。降格・失効の経路を作る
- **学習単位を「型×週」へ**上げる
- **中間指標（いいね・順位）と最終指標（リード）の相関が未検証であることを明示**させる

**予防ルール（横展開可能な一般形）**
1. **正解のない領域で怖いのは「学べないこと」ではなく「ノイズを知識として学ぶこと」。**
   自律学習ループを作るときは、学習機構より先に**間違って学ばないための防波堤**を作る
2. **LLMに判定させる前に、機械が「判定に足る母数か」を判定する。**
   判定肢に「判断保留」を必ず用意し、それを既定にする
3. **棄却は安く、発見は高い。** n=3で「効いた」は言えないが「91件中84件が0」は言える。
   薄い母数では学習目標を「勝ちパターンの発見」から「負けパターンの排除」へ振る
4. **知識ベースには増やす役と同じだけ「疑う・減らす役」を置く。**
   昇格しかしない知識ベースは、時間とともに剥がしにくい誤りを蓄積する
5. **不可逆性には速いもの（外部に出る）と遅いもの（時間とともに剥がしにくくなる）がある。**
   優先順位づけでは後者を見落としやすい。**静かに悪くなるものを先に止める**
