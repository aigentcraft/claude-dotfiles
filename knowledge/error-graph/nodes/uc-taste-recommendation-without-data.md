## 1. Plan / Context
アフィリエイトエージェント Phase -1（2026-08-25）。人間決定②（メディア名・ドメイン）の候補出しで、商標衝突・ドメイン空きを調査し「タメシタ（tameshita.dev）」を第一候補として推奨した。

## 2. Do / The Error
ユーザーの反応:「ダサ。それが伸びるデータ根拠は？」
- 推奨はリスク回避（商標・ドメイン）のみで最適化し、**ブランドの美的品質を評価軸に入れなかった**
- 「推奨」という提示形式が、あたかも成長に寄与するデータ根拠があるかのような含意を持ってしまった（実際には名前と成長を結ぶデータは示していない）

## 3. Check / Root Cause
1. **タスト領域とデータ領域の混同**: ネーミングの「良し悪し」は大部分が人間のタスト決定領域。AIがリスクチェック結果だけで「第一候補」を宣言するのは越権かつ根拠の誤認を招く
2. **成功事例パターンとの照合を怠った**: 日本の伸びている比較・レビューメディア（mybest・360LiFE 等）の命名傾向と照らせば「動詞過去形カタカナ」が異質なことは事前に気づけた
3. **「伸びる根拠」の不在を明示しなかった**: 名前がSEO成長に直結しないこと（Google EMDアップデート以降ドメイン名の順位優遇は廃止）を先に言うべきだった

## 4. Act / Prevention Strategy (Fix)
- **ブランド・デザイン等のタスト領域では、AIは「足切り（リスク）チェック＋方向性の選択肢提示」までに留め、最終の美的選択は人間に委ねる**
- 推奨を出す時は「何がデータに基づき、何がデータ根拠なしか」を明示的に分離して提示する
- ネーミング提案時は成功メディアの命名パターン（実在データ）と照合してから出す

## 5. 追記（同セッション2度目のUC: 2026-08-25）
2度目の候補（Metriq/Benchya/実測部/ツール批評等）も「どれもダサい。安直で思想が浅い」と却下。
- **根本原因**: 機能の直訳（測る・試す・ベンチ＋接尾辞）の組み合わせ生成で、**名前の背後に世界観・思想がなかった**。Wirecutter（雑音を切る態度表明）・Zenn（禅）のような「由来を語れる名前」と、「機能説明の圧縮」は別物
- **予防**: ネーミングは①メディアの思想を一文で言語化 → ②その思想を体現する概念を人類の知的資産（哲学・科学史・法・宗教・文学）から探す → ③名前に圧縮、の順で行う。機能語の組み合わせ生成から始めない

## 6. 追記（同セッション3度目のUC: 2026-08-25）
思想系候補（追試/格物/Nullius/知行等）も「読者の脳内にある言語から遠い。難しい言葉ならいいというものではない」と却下。
- **根本原因**: 思想の深さを衒学的な語彙（漢語・ラテン語）で表現した。読者が日常で一度も口にしない言葉は、どれだけ由来が深くても届かない
- **確定した要件（3点セット）**: ①機能の直訳・安直な複合語は不可 ②名前の背後に思想があること ③**その思想が読者の日常語彙（脳内に既にある言葉）に宿っていること** — 良い名前とは「日常語に思想を発見させる」もの（例: Wirecutter=ありふれた工具名に態度を込める、mybest=日常語 my best）
- **予防**: 思想を定義したら、次は「ターゲット読者がその瞬間に脳内で発している言葉」を列挙し、その中から思想を担える語を選ぶ。辞書・古典からではなく読者の頭の中から採語する

## 7. 追記（同セッション4度目のUC: 2026-08-25）
日常語候補（実際/現物/一次/うのみ/肌感）も「安直なんだって」と却下。
- **根本原因の特定**: 4回に共通する失敗＝**指示的（denotative）命名**。概念→それを直接意味する語、という1ホップ変換で名前を作っていた（実際=actual、うのみ=鵜呑み禁止の直示）。名前が機能を「述べて」いる限り、語彙のレジスタ（カタカナ/漢語/日常語）を変えても安直さは消えない
- **良名の構造**: Wirecutter（工具名→雑音を切る態度）・LDK（間取り略語→暮らし検証誌）のように、**別ドメインからの隠喩転移**で作られる。名前は思想を「述べる」のではなく「想起させる」。聞いた人が由来の物語を知った瞬間に腑に落ちる、という2ホップ構造が必要
- **予防**: 思想を定義 → 読者の語彙内で、その思想を**構造ごと内包する他分野のイメージ・役割・儀式**（例: 毒見役・人柱・炭鉱のカナリア・内見）を探す → 転移させる。概念の同義語探索は禁止

## 8. 追記（同セッション5-6度目のUC: 2026-08-25）
隠喩系（毒見/カナリア）は価値提供の再定義（構造化重視）で流れ、構造化メタファー系（天気図/司書/測量/編纂）も「安直だしダサい」と却下。
- **根本原因**: 既存の一般名詞を**無変換でそのまま**メディア名にしていた（司書・測量=単語であって固有名詞ではない）。隠喩の選定が正しくても、変換ゼロでは「辞書から引いた」感が残り、固有名詞性（指名検索・ブランド所有）も持てない
- **良名の最終条件（累積）**: ①機能の直訳禁止 ②思想内包 ③読者の語彙に根 ④**工芸的変換があること**（Zenn=禅+n、freee=free+e、ほぼ日=フレーズの結晶化。既存語の転用でも「その語をその用途に使う驚き」が要る）
- **プロセス転換**: 候補の乱れ打ちを止め、ユーザーの美意識のリファレンス（ダサくないと感じる実在ブランド名）を先に取得してテイストを校正する
